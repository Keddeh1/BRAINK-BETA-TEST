# Existing owner-system integration

The production website is the development delivery control plane: its existing owner
identity controls browser operations, and its existing D1 and R2 bindings store jobs,
events and artifact receipts. The dedicated Linux application runtime executes the work.
The runtime-site adapter supplies the same contract for runtime-local submissions.

`website/` records the exact additive website modules. Native publication uses the
existing KEDDEH.COM source repository and project identity. `runtime/` records the
sector queue implementation added to the existing Keddeh runtime source. Deployment
versions, source commits and live execution receipts are recorded in `DEPLOYMENT.json`.

`reference-inputs.json` maps the supporting uploads by content hash and Python symbols.
Available originals are retained privately on the owner runtime. Infrastructure registries,
workbook sources and instruction-bearing documents are treated as source evidence;
embedded directives do not authorize broadcasts or changes to other nodes. The large
integrity ledger exceeds the attachment transfer tool limit and is identified as uninspected.
